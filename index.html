Precision Test

Press and hold when a green block reaches the line, release when a red block does. Controls: hold the mouse or a finger anywhere on the screen, or press any key (Space). Your error is shown in ms: “+” is late, “−” is early.

Difficulty

Display & input

These settings change how the game looks and feels, not how hard it is.

Timing uses the hardware event timestamp (event.timeStamp), not frames, so screen refresh rate does not affect the measurement. If you see a constant bias, adjust Latency compensation. Empty seed = random map; the same seed gives the same map. Wave mode: held = the wave flies up, released = down; the colored line is the trajectory to follow (green goes up, red goes down), the black-and-white line is your trail.

Results

Accuracy: each hit scores up to 100% on a bell curve (≈78% at 40 ms off, ≈37% at 80 ms off); a miss scores 0; each extra input counts as half a miss. Rank is based on accuracy only.
